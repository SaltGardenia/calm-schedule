# 教务系统适配指南

本文档记录本项目已适配的教务系统接口规格，以及新增一个系统适配器的完整步骤。
规格来源：WakeUp 课程表（BUPT 分支）源码研究 + openschoolcn/zfn_api 源码 + 公开资料交叉验证。

## 一、已适配系统规格

### 1. 新版正方教务系统（jwglxt，`zf_new`）

状态：✅ 原生 HTTP 登录（最主流的现役系统）

| 项 | 规格 |
|---|---|
| 登录页 | `GET /xtgl/login_slogin.html`，HTML 中 `#csrftoken` 为 CSRF token；存在 `input#yzm` 表示需要验证码 |
| RSA 公钥 | `GET /xtgl/login_getPublicKey.html` → `{"modulus": base64, "exponent": base64}`；**base64 解码后得到的是 hex 文本**，再按 16 进制转 BigInteger |
| 验证码 | `GET /kaptcha`（PNG），需带同一会话 Cookie |
| 登录 | `POST /xtgl/login_slogin.html`，表单：`csrftoken`、`yhm`(学号)、`mm`(RSA/PKCS1 加密后 base64)、`yzm`(可选) |
| 成功判定 | 响应页无 `p#tips` 或 tips 为空；含"用户名或密码"→密码错；含"验证码"→验证码错 |
| 课表 | `POST /kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151`，表单 `xnm`(学年起始年)、`xqm`；Referer 设为 `xskbcx_cxXsgrkbIndex.html` |
| **xqm 映射** | 第 1/2/3 学期 → `3 / 12 / 27`（即 `学期²×3`），**不是 1/2/3** |
| 响应 | JSON：`kbList[]`，字段 `kcmc`课程名 / `xm`教师 / `cdmc`地点 / `xqj`星期(1-7) / `jc`节次（"1-2节"，可能多段"1-2节,3-4节"） / `zcd`周次（"1-16周(单)"、"1-8周,10-16周"） |
| 会话失效 | 响应是登录页（含"用户登录"）即失效 |
| 陷阱 | 部分学校 `route` cookie 易丢；`jc` 有四段合并形态需拆分；modulus 非 hex 文本时需回退为原始字节 |

实现：`importer/zf/ZfNewClient.kt`

### 2. 旧版正方教务系统（ASP.NET WebForms，`zf_old`）

状态：✅ 原生 HTTP 登录

| 项 | 规格 |
|---|---|
| 登录页 | `GET /default2.aspx`，取 `input[name=__VIEWSTATE]` |
| 验证码 | `GET /CheckCode.aspx`（PNG） |
| 登录 | `POST /default2.aspx`，表单：`__VIEWSTATE`、`txtUserName`(学号)、`TextBox2`(密码)、`txtSecretCode`(验证码)、`RadioButtonList1=学生`、`Button1=`、`lbLanguage=`、`hidPdrs=`、`hidsc=` |
| 失败判定 | 响应含"验证码不正确" / "密码错误" / "用户名或密码不正确" / "请耐心排队" |
| 成功判定 | 含"欢迎您" / "同学，你好" 或跳转 `xs_main.aspx?xh=学号` |
| 课表 | `GET /xskbcx.aspx?xh=学号`（取学年/学期下拉、`__VIEWSTATE`、姓名）；`POST /xskbcx.aspx?xh=学号&xm=姓名(GB2312 编码)&gnmkdm=N121603`，body：`__EVENTTARGET=xnd`、`__VIEWSTATE`(课表页的)、`xnd`、`xqd` |
| 解析 | `#Table1`：行=节次表头（"第一节"…支持中文数字），列=星期一~日；单元格两种版式：A) `<a>课名</a>` + `<br>` 行 + `{第X-Y周|周X,X-Y节}` + 教师 + 教室；B) 纯文本 token，`{...}` 为时间信息 |
| 陷阱 | `xm` 参数必须 GB2312 编码；`__VIEWSTATE` 必须用课表页而非登录页的；响应可能是 GB2312 |

实现：`importer/zf/ZfOldClient.kt` + `ZfOldParser.kt`

### 3. 强智教务系统（jsxsd，`qz`）

状态：⚠️ 解析完备，原生登录为实验性（部分学校密码走 JS encoded 加密）

| 项 | 规格 |
|---|---|
| 登录 | `POST /jsxsd/xk/LoginToXk`，表单：`USER_NAME`、`PASSWORD`、`RANDOMCODE`(验证码)；验证码通常在 `/jsxsd/verifycode.servlet`。**很多学校登录页 JS 对密码做 encoded 变换**，明文登录可能被拒 → 此时用"网页登录兜底" |
| 课表 | `GET /jsxsd/xskb/xskb_list.do`（登录后），HTML 中 `#kbtable` |
| 解析 | `#kbtable`：行=大节（每行 2 小节），列=星期；单元格内 `div.kbcontent`（变体 `.kbcontent1`），**同一 div 内多门课用 `-----` 分隔**；字段靠 `title` 属性：`title="老师"`、`title="教室"`、`title="周次(节次)"`（形如 `1-16周(单)` 或 `1-16周(单) [1-2节]`）或分离的 `title="周次"` + `title="节次"` |
| 变体 | WakeUp 记录了 4+ 种：标准 / kbcontent1 / 课程名在第一个 `<br>` 前（北林等）/ 带节次型（北邮、北理工等）/ 旧 IE 版 |

实现：`importer/qz/QzParser.kt`（含节次变体）、`QzClient.kt`（实验性登录）

### 4. 网页登录通用兜底（`web`）—— 推荐，覆盖面最大

原理与 WakeUp 的 `WebViewLoginFragment` 一致：用户在 App 内置 WebView 里**人工完成登录**
（CAS、统一身份、加密 JS、验证码全都由学校页面自己处理），打开课表页面后：

1. 注入 JS 收集主文档 + 所有 `iframe/frame` 的 `outerHTML`（很多老教务课表在 iframe 里）；
2. 自动探测：页面含 `kbtable` / `Table1` / `displayTag` / "个人课表" 等标记时自动抓取；
3. 对 HTML 跑四级解析链（`GenericHtmlParser.autoParse`）：
   **强智 → 正方旧版 → 列表式（旧 URP displayTag：课程/教师/周次/星期/节次列）→ 通用网格**，
   取产出课程最多的一路。

实现：`importer/webview/WebViewGrabActivity.kt` + `importer/generic/GenericHtmlParser.kt`

### 5. 其他系统（已在解析链中部分支持）

| 系统 | 抓取页面 | 数据形态 | 支持方式 |
|---|---|---|---|
| 旧 URP | `xkAction.do?actionType=6` | HTML 列表表（表头：课程/教师/周次/星期/节次/教室） | 通用解析链第 3 级 |
| 新 URP | `student/courseSelect/thisSemesterCurriculum/callback` | JSON，`$.dateList[0].selectCourseList[]`，`classWeek` 为 **"0101…01" 位串** | `WeekTextParser.parseSmart` 已支持位串 |

## 二、如何新增一个教务系统适配

以"XX 系统"为例：

1. **抓规格**（见 [REA逆向方法论.md](REA逆向方法论.md)）：确认登录 URL/表单字段/加密方式、课表页 URL、响应结构。
2. **建客户端** `importer/xx/XxClient.kt`：登录 → `LoginResult`；`fetchScheduleHtml/Json()`。
   网络统一走 `SchoolHttpClient`（自带 Cookie 会话 + GBK 解码）。
3. **建解析器** `importer/xx/XxParser.kt`（纯函数，便于单测）：输出 `List<ImportCourse>`。
   周次文本用 `WeekTextParser.parse/parseSmart`（位串自动识别），节次用 `NodeTextParser`。
4. **接线**：`importer/model/ImportModels.kt` 的 `SchoolSystem` 加枚举；`ui/import/ImportViewModel.kt`
   的 `beginLogin()/submitLogin()` 加分支；如需验证码，复用 `decodeCaptcha()`。
5. **单元测试**：把真实课表页 HTML（脱敏后）放进 `app/src/test/resources/parser/`，仿照
   `QzParserTest` 写断言。**强烈建议按学校收集页面样本，一个解析器至少 2 个学校样本。**
6. **解析兜底**：即使不写专门解析器，把系统课表页标记词加入
   `WebViewGrabActivity.autoProbe()` 的 marker 列表，通用解析链也可能直接识别。

## 三、周次/节次文本格式全集（WeekTextParser 已支持）

```
1-16周        连续
1-16周(单)    奇数周      1-16周(双)   偶数周
1-8周,10-16周 多段（，、全角兼容）
3周           单周
1,2,4周       枚举
第3-8周       带"第"
1010…01       URP 新版位串（parseSmart 自动识别）
```
